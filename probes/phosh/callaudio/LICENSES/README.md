The original archive supplies the GPL version 3 text and no separate
`COPYING.LIB`. Its README describes the daemon as GPLv3+.
The `libcallaudio.c` and D-Bus data build-file notices instead declare
`LGPL-2.1-or-later`; the root Meson file has a GPL-3.0-or-later SPDX notice
and `LGPLv3+` project metadata. These declarations are recorded without
silently reconciling or rewriting them. The client-only patch does not
change the original notices or claim a new license for the upstream code.
